Understanding the jQuery :reset Selector

In jQuery, specialized form selectors simplify the process of locating specific user interface controls across a document. This article explores the jQuery :reset pseudo-class selector, identifying the precise HTML elements it targets in a standard web form, explaining how it functions, and outlining the recommended syntax for optimal performance.

Elements Targeted by :reset

The jQuery :reset selector exclusively matches elements designed to reset all controls in an enclosing form to their initial default values. In standard HTML, it selects two specific elements:

  • <input type="reset">
  • <button type="reset">

Any other element will be ignored by this selector. For instance, a generic <button> without a type attribute will not be selected, as browsers assign the default behavior of type="submit" to untyped buttons inside forms. Similarly, elements such as <input type="button">, <input type="submit">, or standard anchors styled as buttons are excluded.

Basic Syntax and Examples

To target every reset control across the entire document, use the selector directly:

// Selects all input and button elements with type="reset"
$(':reset').css('border', '1px solid red');

To restrict the search to a specific form, scope the selector to the parent container:

// Selects reset controls only within the contact form
$('#contact-form :reset').prop('disabled', true);

Performance Considerations

Because :reset is a jQuery extension and not part of the official W3C CSS specification, browsers cannot evaluate it using the native querySelectorAll() engine. When jQuery encounters :reset, it must filter elements using its own internal engine, which is slower on large or complex documents.

To achieve better performance, use standard CSS attribute selectors to target the exact same elements:

// Native-compatible equivalent providing faster DOM traversal
$('input[type="reset"], button[type="reset"]');

This approach allows the browser to utilize its built-in selector engine while targeting the exact same set of reset elements.
